# Meme Vault v0.4 完成交接

更新日期：2026-07-30
开发分支：`codex/v0.4-composite-meme-relations`
基线：v0.3.3；当前前端包版本：v0.4.0。

> v0.4 功能、迁移、文档和自动化验收已完成。

## 已交付

### 有序多图 Meme

- 新增 `MemeImage`；`Meme.images` 按零基 `position` 排序。
- `file_hash` 在图片库全局唯一，`(meme_id, position)` 唯一。
- 第一张图片自动作为封面；旧 `memes` 图片字段保留为兼容投影并在排序、删除后同步。
- 支持追加单图、删除非最后图片、提交完整 ID 顺序排序。
- 删除图片会清理该原图与缩略图；删除完整 Meme 会清理整组文件。
- 获取 Meme 时会检查完整图片组文件，而不只检查封面。

### SQLite 迁移

- `create_tables()` 创建 `meme_images` 和 `meme_relations`。
- 所有 SQLite 连接自动执行 `PRAGMA foreign_keys=ON`，数据库会实际执行外键校验和删除级联。
- 旧 Meme 在启动时幂等回填一张 position=0 的 `MemeImage`。
- 回填只复制旧元数据，不移动或改写磁盘文件；重复启动不会重复插入。
- 非 SQLite 数据库不执行 SQLite 专用 SQL。

### 前端图片组

- 瀑布流只渲染封面，多图显示数量角标。
- 详情页按顺序纵向显示完整图片组，并明确标识封面。
- 支持单图追加、非最后图片删除和拖拽排序。
- 图片操作期间禁用冲突控件，提供拖拽反馈和就地错误信息。
- 原图查看器可从任意索引打开，支持前后按钮和左右方向键；关闭后清空查看状态。

### AI 多图

- 新增 `AIInputImage` 和正式 `analyze_images()` 调用路径。
- 服务按 position 读取全部原图。
- OpenAI Responses 与兼容 Chat payload 均按序包含“第 N 张”说明和图片。
- 系统提示明确全部图片属于同一个有序 Meme，只生成一份组级描述、标签和模板判断。
- 每次只保存一条 `MemeAIAnalysis`，确认前不修改 Meme。

### 手动弱关联

- 新增规范化无向 `MemeRelation`：小 ID 在 `meme_a_id`，大 ID 在 `meme_b_id`。
- 关系双向可查、只返回直接边、不传递；禁止自身关系和重复边。
- 支持批量添加前完整校验、单条移除，以及删除 Meme 时清理 incident edges。
- 前端选择 Meme 后加载并清空旧关系状态；添加对话框按标题/描述搜索，排除自身和已关联项，可多选一次提交。
- 直接关系项显示缩略图、标题和描述，可跳转详情或单条移除，并有加载、空状态、忙碌和错误反馈。

## v0.4 API

- `POST /api/memes/{meme_id}/images`
- `PATCH /api/memes/{meme_id}/images/order`
- `DELETE /api/memes/{meme_id}/images/{image_id}`
- `GET /api/memes/{meme_id}/relations`
- `POST /api/memes/{meme_id}/relations`
- `DELETE /api/memes/{meme_id}/relations/{related_meme_id}`

`MemeResponse` 新增有序 `images` 与 `image_count`；旧封面字段继续对应第一张图片。

## 关键回归修复

- 修复直接 `session.delete(image)` 后 ORM 集合仍保留已删除图片的问题，改由 delete-orphan 集合移除。
- 修复拖拽重排后删除封面时，SQLite 可能因重编号更新顺序触发 `(meme_id, position)` 唯一约束的问题；删除和排序现在都先使用临时负位置。
- 修复删除完整复合 Meme 只删除封面文件的问题。
- 修复次要图片文件缺失时 `get_meme()` 仍成功的问题。
- 新增图片与关系接口在组内任一文件缺失时统一返回 410，不再泄漏为 500。
- API 兼容封面字段直接从有序 `images[0]` 派生，即使旧投影漂移也保持响应一致。
- 关系加载失败不再产生未处理 Promise rejection，也不会短暂显示上一条 Meme 的关系。
- 关系跳转直接使用已加载关系对象，不依赖该 Meme 是否仍在当前分页列表中。
- 关系移除使用请求令牌隔离交错响应，旧请求完成不会提前解除新请求的忙碌状态。
