# Meme Vault v0.1.1 Backend Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成图片 HTTP URL、可迁移文件引用、缺图删除、关键词搜索、Pytest 临时目录配置及 v0.1.1 文档收尾。

**Architecture:** 保持 API → Service → Repository/Storage 分层。`create_app()` 通过 `app.state` 将同一组媒体目录同时交给 `StaticFiles` 和 `get_meme_service()`；Storage 负责安全解析新文件名与旧路径；API 使用唯一转换函数生成公开 URL。

**Tech Stack:** Python 3.11+、FastAPI、Starlette StaticFiles、SQLAlchemy、Pydantic、Pillow、Pytest、HTTPX。

## Global Constraints

- 保持 API → Service → Repository/Storage 的调用链。
- 不引入数据库迁移框架，不重命名现有数据库字段。
- 不自动批量修改已有数据库记录。
- 不创建或修改 TypeScript 前端文件。
- 不进行与 v0.1.1 无关的重构。
- 静态文件服务与 `get_meme_service()` 创建的 `ImageStorage` 必须使用同一组目录。
- 挂载 `StaticFiles` 前必须创建原图与缩略图目录。
- 旧 Windows 路径必须先把反斜杠统一为正斜杠，再提取文件名。
- `MemeResponse.thumbnail_url` 必须是 `str | None`。
- 所有 Meme API 响应必须由唯一的 `_to_meme_response()` 转换函数生成。

```python
from pathlib import Path, PurePosixPath

@staticmethod
def filename_from_reference(reference: str | Path) -> str:
    normalized = str(reference).replace("\\", "/")
    filename = PurePosixPath(normalized).name
    if not filename:
        raise ValueError("File reference does not contain a filename")
    return filename
```

将 `_path_inside` 改为：

```python
@classmethod
def _path_inside(cls, path: str | Path, root: Path) -> Path:
    candidate = Path(path)
    if candidate.is_absolute():
        resolved_candidate = candidate.resolve()
        try:
            resolved_candidate.relative_to(root)
        except ValueError:
            pass
        else:
            return resolved_candidate

    resolved = (root / cls.filename_from_reference(path)).resolve()
    try:
        resolved.relative_to(root)
    except ValueError as error:
        raise ValueError("Path is outside configured storage") from error
    return resolved
```

```python
from app.models.meme import Meme
from app.schemas.meme import MemeResponse, MemeUpdate, TagResponse

def _to_meme_response(meme: Meme) -> MemeResponse:
    image_name = ImageStorage.filename_from_reference(meme.file_path)
    thumbnail_name = (
        ImageStorage.filename_from_reference(meme.thumbnail_path)
        if meme.thumbnail_path is not None
        else None
    )
    return MemeResponse(
        id=meme.id,
        title=meme.title,
        description=meme.description,
        source=meme.source,
        original_filename=meme.original_filename,
        stored_filename=meme.stored_filename,
        image_url=f"{IMAGES_URL_PREFIX}/{image_name}",
        thumbnail_url=(
            f"{THUMBNAILS_URL_PREFIX}/{thumbnail_name}"
            if thumbnail_name is not None
            else None
        ),
        mime_type=meme.mime_type,
        file_size=meme.file_size,
        width=meme.width,
        height=meme.height,
        file_hash=meme.file_hash,
        created_at=meme.created_at,
        updated_at=meme.updated_at,
        tags=[TagResponse.model_validate(tag) for tag in meme.tags],
    )
```

在 Repository 中：

```python
from sqlalchemy import func, or_, select

def list(
    self,
    *,
    offset: int = 0,
    limit: int = 100,
    tags: Sequence[str] | None = None,
    q: str | None = None,
) -> list[Meme]:
    statement = select(Meme)
    search = (q or "").strip().lower()
    if search:
        statement = statement.where(
            or_(
                func.lower(Meme.title).contains(search, autoescape=True),
                func.lower(func.coalesce(Meme.description, "")).contains(
                    search,
                    autoescape=True,
                ),
            )
        )
```
