# Meme Vault v0.3.1 API 设置实施说明

## 目标

在不扩展到 v0.4 文案生成功能的前提下，为 v0.3 图片分析增加网页配置入口，让用户可以管理模型厂商、密钥和模型，并明确选择当前图片分析模型。

## 后端设计

- 新增 `ai_providers` 与 `ai_models` 两张表。
- 厂商保存名称、协议、基础 URL、密钥密文、密钥末四位提示、超时、重试次数、重试间隔与启用状态。
- 模型保存厂商、显示名称、厂商模型标识、视觉能力、启用状态与当前分析模型状态。
- 同一时间只允许一个启用且支持视觉的模型作为图片分析模型。
- API Key 使用 Fernet 加密。密钥来自 `AI_SETTINGS_ENCRYPTION_KEY`，未配置时生成到被 Git 忽略的 `data/.ai_settings.key`。
- 设置 API 永不返回 API Key 明文或密文，只返回 `has_api_key` 和 `api_key_hint`。
- 图片分析优先使用网页选中的模型；没有选中模型时回退到 v0.3 的 `OPENAI_*` 环境变量。

## 厂商和协议

- OpenAI：`openai_responses`，默认 `https://api.openai.com/v1`。
- Qwen：`openai_chat_completions`，默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`。
- DeepSeek：`openai_chat_completions`，默认 `https://api.deepseek.com`。
- 自定义：可选择上述任一协议并填写 HTTP(S) 基础 URL。

DeepSeek 预置模型当前标记为仅文本，不能设为图片分析模型。Qwen 和 OpenAI 的常用视觉模型由预设提供；在线刷新只导入模型标识，未知模型默认停用，避免错误推断能力。

## 前端设计

- 顶部工具栏新增“API 设置”。
- 使用全屏原生 `<dialog>` 展示“模型厂商”和“模型列表”两个标签页。
- 厂商编辑器支持模板、名称、URL、协议、API Key、超时、重试和启用状态。
- 模型编辑器支持显示名称、模型标识、视觉能力与启用状态。
- 厂商列表提供测试、刷新、编辑与删除。
- 模型列表提供当前分析模型选择、编辑与删除，并清晰展示“支持视觉/仅文本”。
- 密钥编辑时留空表示保持不变，勾选清除后 PATCH 才发送 JSON `null`。
- 设置主界面和编辑器保留输入及错误信息；点击内容区不关闭，只在明确关闭或点击 `<dialog>` 背景时关闭。

## 接口

- `GET /api/ai-settings/presets`
- `GET|POST /api/ai-settings/providers`
- `PATCH|DELETE /api/ai-settings/providers/{provider_id}`
- `POST /api/ai-settings/providers/{provider_id}/test`
- `POST /api/ai-settings/providers/{provider_id}/refresh-models`
- `GET|POST /api/ai-settings/models`
- `PATCH|DELETE /api/ai-settings/models/{model_id}`

## 验证

- Pytest 验证预设、密钥加密和掩码、PATCH 保留/清除密钥、模型激活约束、连接测试与模型刷新。
- Vitest 验证设置 API 请求、模板填充、厂商保存、模型切换和现有 Meme 工作流回归。
- 生产构建后用浏览器验证响应式布局和完整交互。
